Brimkern SDK — e-commerce & local RAG demo

This page shows a smart assistant embedded in an online store. The model runs directly on your browser's GPU and has a local knowledge base (size guide, returns, shipping).

📚 Injected knowledge base (local RAG)

The assistant below was configured with the store's real business rules. Try asking it questions through the widget in the bottom-right corner:

👟 Size guide
EU/US/cm conversions, half a size up for running shoes.
📦 Returns & exchanges
100% free within 30 days, refunded within 5 working days.
🚚 Shipping
Free from €50 (2–4 days), 24h express available.
💡 Questions to try:
“How do running shoes fit?” “I wear a 42, what is that in cm?” “How long do I have to return an item?” “Are returns free?”

💻 The integration code used on this page

<script src="/sdk.js"></script>
<script>
  Brimkern.embed({
    title: "Store Assistant",
    lang: "en",
    system: "You are the official store assistant. Answer questions about sizing, shipping and returns precisely, from the reference notes.",
    knowledge: [
      {
        title: "Shoe size guide",
        text: "Sneakers fit true to size. Running shoes and studded boots: order half a size up. EU 40 = 25.5cm, EU 41 = 26cm, EU 42 = 27cm, EU 43 = 27.5cm, EU 44 = 28.5cm."
      },
      {
        title: "Returns policy",
        text: "Returns are 100% free within 30 days in the original box. Refunds are issued within 5 working days."
      },
      {
        title: "Shipping",
        text: "Standard delivery is free from €50 (2 to 4 days). 24h express costs €7.90."
      }
    ],
    knowledgeBudget: 1200,
    showSources: true
  });
</script>

Brimkern SDK — Démo E-Commerce & RAG Local

Cette page illustre l'intégration d'un assistant intelligent pour site e-commerce. Le modèle tourne directement sur le GPU de votre navigateur et dispose d'une base de connaissances locale (guide des tailles, retours, livraisons).

📚 Base de connaissances injectée (RAG Local)

L'assistant ci-dessous a été configuré avec les règles métier réelles du magasin. Essayez de lui poser des questions via le widget en bas à droite :

👟 Guide des Tailles
Correspondances EU/US/CM, recommandation +1/2 pointure pour le running.
📦 Retours & Échanges
100% gratuits sous 30 jours, remboursement sous 5 jours.
🚚 Expédition
Gratuite dès 50€ (2-4 jours), Express 24h disponible.
💡 Exemples de questions à tester :
« Comment taillent les chaussures de running ? » « Je fais du 42, quelle taille en cm ? » « Combien de temps pour retourner un article ? » « Les retours sont-ils gratuits ? »

💻 Code d'intégration utilisé sur cette page

<script src="/sdk.js"></script>
<script>
  Brimkern.embed({
    title: "Conseiller Boutique",
    lang: "fr",
    system: "Tu es le conseiller officiel. Réponds précisément aux questions sur les tailles, livraisons et retours à partir des fiches.",
    knowledge: [
      {
        title: "Guide des tailles chaussures",
        text: "Les baskets taillent normalement. Modèles running et crampons : prendre 1/2 taille au-dessus. EU 40 = 25.5cm, EU 41 = 26cm, EU 42 = 27cm, EU 43 = 27.5cm, EU 44 = 28.5cm."
      },
      {
        title: "Politique de retours",
        text: "Retours 100% gratuits sous 30 jours dans la boîte d'origine. Remboursement sous 5 jours ouvrés."
      },
      {
        title: "Livraison",
        text: "Livraison standard gratuite dès 50€ d'achat (délai 2 à 4 jours). Express 24h à 7,90€."
      }
    ],
    knowledgeBudget: 1200,
    showSources: true
  });
</script>
