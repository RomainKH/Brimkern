Acme Docs — Local Q&A Starter

Open the chat widget in the bottom-right corner to ask questions about the documentation below. The widget indexes the page DOM automatically and runs on your GPU.

Installation

Install Acme CLI with npm i -g acme-cli. Node.js 18 or higher is required. Configuration lives in acme.config.json at the project root.

Authentication

Run acme login to authenticate via OAuth. Tokens are stored in your OS keychain and expire after 30 days. CI pipelines can set the ACME_TOKEN environment variable.

Deployments & Rollbacks

Deploy with acme deploy --prod. Every release gets an immutable URL. Roll back to the previous release at any time with acme rollback.
