# Brimkern — an LLM inside the tab

A **static** Space (no Hugging Face GPU): the **LFM2.5-230M** model in the **BRIK** format (149 MB) is
streamed from the Hub by HTTP Range requests, then executed on the **visitor's GPU** through
hand-written WGSL kernels. The prompt and the generation never leave the machine, and after the first
load the page works **offline**.

- Engine, BRIK format and embeddable SDK: <https://brimkern.com>
- Weights: [`romainkh14/LFM2.5-230M_BRIK`](https://huggingface.co/romainkh14/LFM2.5-230M_BRIK)
  (base [`LiquidAI/LFM2.5-230M`](https://huggingface.co/LiquidAI/LFM2.5-230M), LFM 1.0 license)
- Open **any** single-file GGUF or BRIK from the Hub in the same engine:
  `https://brimkern.com/chat?model=author/repo`
- All BRIK models: <https://huggingface.co/models?other=brimkern>

Measured on an Apple Silicon laptop, production build: **~158 tok/s** decoding, prefill 2 289 tok/s.
Benches are in the repository ([`scripts/e2e/`](https://github.com/RomainKH/Brimkern/tree/main/scripts/e2e)) —
every number published by this project comes from one of them.

Requirements: a WebGPU browser (Chrome/Edge 113+, Safari 18+).

*This Space's content is generated by `npm run build:hf-space` from the project repository
(`hf/space/` + the bundled SDK). The Space code is MIT; the weights keep their own license.*
